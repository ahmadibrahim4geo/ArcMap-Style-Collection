BGS Geology 50k Styles - README
==============================
Folder: BGS Geology 50k Styles  |  Project: Styles ArcMap
Date: 2026-09-29  |  ArcGIS Pro only (no ArcMap .style from BGS)

CONTENTS
--------
- BGS_Geology.stylx ................. official BGS style for ArcGIS Pro (Insert > Add Style)
- Docs\ ............................. 5 layer files (.lyrx): bedrock / superficial / artificial / linear / mass_movement
- Originals\ ........................ BGS-Geology-50k-ESRI-styles.zip (original package, ~810 KB)
- Sources\المصادر-والروابط.txt ..... sources with website + download links
- Preview\ .......................... add your own legend screenshots here

QUICK START
-----------
1. ArcGIS Pro: Insert > Add Style > select BGS_Geology.stylx
2. Add data then apply the .lyrx files in Docs\ for ready-made symbology (1:50k bedrock/superficial/...).
3. There is NO ArcMap .style version from BGS (.stylx cannot convert back to .style).

SOURCES
-------
- Main page: https://www.bgs.ac.uk/download/bgs-geology-50k-esri-styles/ (published 11-02-2022)
- Check BGS terms of use (open data with conditions, not pure Public Domain like USGS).
