Petroleum Styles - README
=========================
Folder: Petroleum Styles (split from ESRI Industry Styles)  |  Project: Styles ArcMap
Date: 2026-09-29

CONTENTS
--------
- Petroleum.stylx .................. official ESRI Pro style (wells/facilities)
- Petroleum.style .................. ArcMap equivalent (from local ArcMap 10.8 install)
- Shell-2016-RedOil-Pro.stylx ...... Shell cartographic standard, red version (~10 MB, Pro only)
- Shell-2016-GreenOil-Pro.stylx .... Shell cartographic standard, green version (~10 MB, Pro only)
- Sources\المصادر-والروابط.txt .... item links + gallery links
- Preview\ ......................... add your own legend screenshots here

QUICK START
-----------
- Pro: Insert > Add Style > any .stylx above.
- ArcMap: Style Manager > Add Style to List > Petroleum.style
  (Shell styles have NO .style version - use Petroleum.style as ArcMap alternative).
