Soils SSURGO Styles - README
============================
Folder: Soils SSURGO Styles  |  Project: Styles ArcMap

CONTENTS
--------
- Soils-EURO-ESRI.stylx ......... ESRI European soils style for Pro (base for soil-map coloring)
- Soils EURO.style ............... ArcMap equivalent (from local ArcMap 10.8 install)
- Soils EURO - Editable.style .... same-size copy kept as editable spare
- Soils EURO.ldb ................. legend file
- Sources\المصادر-والروابط.txt .. sources + SSURGO download links
- Preview\ ....................... add your own legend screenshots here

QUICK START
-----------
1. Pro: Insert > Add Style > Soils-EURO-ESRI.stylx
2. ArcMap: Style Manager > Add Style to List > Soils EURO.style
3. Data (large, per HUC-8 area, not one batch): USDA Gateway https://gdg.sc.egov.usda.gov/GDGHome_DirectDownLoad.aspx
   or interactive https://websoilsurvey.nrcs.usda.gov/ (>36M features total).
