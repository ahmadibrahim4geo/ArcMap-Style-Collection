QUICK START
-----------
1. Install fonts first: copy FGDCGeoSym*.ttf + FGDCGeoAge.otf to C:\Windows\Fonts
   (if symbols do not show in Pro, also copy to C:\Program Files\ArcGIS\Pro\Resources\Fonts).
2. ArcMap: Style Manager > Add Style to List > GSC_FGDC_GeologicMapSymbols.style
3. Pro: Insert > Add Style > GSC_FGDC_GeologicMapSymbols.stylx (or unzip FGDC_STYLX.zip for the full standard).
