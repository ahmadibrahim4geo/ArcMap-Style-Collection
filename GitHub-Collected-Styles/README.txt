## طريقة التركيب في ArcMap 10.x
1. انسخ مجلد GitHub-Collected-Styles إلى C:/Users/<اسمك>/AppData/Roaming/ESRI/Desktop10.x/ArcMap/Styles أو أي مكان
2. افتح ArcMap > Customize > Style Manager > Styles > Add Style to List
3. اختار الملفات الستة
4. ستظهر الرموز والـ Color Ramps في Symbology
