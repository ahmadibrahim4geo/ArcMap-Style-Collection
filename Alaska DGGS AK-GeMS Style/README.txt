Alaska DGGS AK-GeMS Style - README
====================================
Folder: Alaska DGGS AK-GeMS Style  |  Project: Styles ArcMap
Date: 2026-09-29  |  ArcMap: 10.x (v1) / ArcGIS Pro (v2)

CONTENTS
--------
- AK_GeMS_symbology_ver_1.style ..... ArcMap style (~32 MB, use directly in ArcMap)
- AK_GeMS_symbology_ver_2.stylx ..... ArcGIS Pro style (~36 MB, Pro only)
- Originals\ ........................ original download packages (mp169 + mp169v2 zips)
- Docs\ ............................. mp169.pdf + mp169v2.pdf reports + ver_1/ver_2 .xlsx symbol documentation
- Sources\المصادر-والروابط.txt ..... sources with website + download links
- Preview\ .......................... add your own legend screenshots here

QUICK START
-----------
1. ArcMap: Customize > Style Manager > Styles... > Add Style to List > select AK_GeMS_symbology_ver_1.style
2. ArcGIS Pro: Insert > Add Style > select AK_GeMS_symbology_ver_2.stylx (v2 recommended)
3. Symbol documentation (code + CMYK like 40X0) is in Docs\*.xlsx.
