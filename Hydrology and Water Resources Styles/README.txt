- Preview\ .................................. add your own legend screenshots here

QUICK START
-----------
1. Pro: Insert > Add Style > select a .stylx file.
2. ArcMap: Style Manager > Add Style to List > select Water Wastewater.style or Utilities.style
   (no direct .stylx -> .style conversion exists).
3. Data: NHD scegliere via The National Map Download Client or https://hydro.nationalmap.gov/arcgis/rest/services/nhd/MapServer
