# ArcMap_Style — كل ستايل QGIS له ملف .style مستقل
- Individual/ : ‏75 ملف .style (ملف لكل مصدر: 33 باليتة + 19 qml + ‏21 مكتبة XML + ‏2 ramps) + ‏Individual_Report.csv
- QGIS_Converted.style : نسخة مجمعة بكل الرموز (12,065 رمز)
- _jobs.txt : جرد المصادر

التفعيل في ArcMap: Customize > Style Manager > Styles > Add Style to List > اختار الملف > OK
ملحوظة: أسماء الرموز داخل كل ملف = أسماء QGIS الأصلية، والـ Category = اسم المصدر.
