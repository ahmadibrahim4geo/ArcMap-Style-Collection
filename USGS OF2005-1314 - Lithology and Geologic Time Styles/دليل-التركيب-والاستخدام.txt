دليل تركيب واستخدام ستايلات الليثولوجيا والزمن الجيولوجي OF2005-1314
========================================================================
1) المحتويات
------------
- ستايلات الزمن الجيولوجي: DNAG.style (مقياس 1983) / ISC.style / ISC_USGS.style (بألوان USGS) / SGMC.style.
- ستايلات الليثولوجيا: lith4_3.style / lith6_1.style / lith6_2.style.
- DNAG.ldb => ملف مفتاح الخريطة الخاص بـ DNAG.
- Originals\ => الحزمة الأصلية المضغوطة من موقع USGS.
- Docs\ => تقرير PDF (21 صفحة يشرح منهجية التوحيد) + جدولا Excel بقيم RGB.
- Sources\ => ملف المصادر والروابط.

2) التركيب
----------
- في ArcMap (9 وما بعده): Style Manager > Add Style to List > اختر أي ملف .style.
- في Pro: Insert > Import Map Styles لتحويل الـ .style إلى .stylx.

3) الاستخدام
------------
- مخصصة لتلوين المضلعات (color fills) للوحدات الليثولوجية والزمنية.
- عدّل الألوان يدوياً بالاعتماد على قيم RGB في ملفي Excel داخل Docs\.
