ABOUT THE COLLECTION

ما هي هذه المكتبة؟ ولماذا هي الأهم لمجتمع الـ GIS؟

المشروع كله عن ستايلات الأرك ماب. تجميعة نادرة تجمع ستايلات Esri الرسمية مع معايير المسوح الجيولوجية العالمية ومنظمات المياه والنفط والبيئة، مرتبة في 27 مجلداً تخصصياً لتوفير أعلى معايير الإخراج الكارتوجرافي للمهندسين والباحثين.

معايير الجيولوجيا العالمية (FGDC & GeMS)

تغطية شاملة لرموز وهيئات المسوح الجيولوجية: USGS FGDC 2006 والمعيار الاتحادي GeMS، وهيئة المسح الجيولوجي البريطانية (BGS 50k)، وهيئة ألاسكا (DGGS AK-GeMS)، ومقاييس 1:24,000، وأزمنة وصخور OF2005 بالأكواد والخطوط الأصلية.

الهيدرولوجيا وشبكات المياه والمرافق

ستايلات متكاملة لشبكات البنية التحتية والمياه والصرف الصحي تشمل ستايلات برامج Bentley الشهيرة (WaterGEMS و SewerGEMS)، بالإضافة لرموز المرافق والموارد المائية مع النسخ العربية ثنائية اللغة.

قطاع البترول والتعدين والطاقة

ستايلات آبار النفط والغاز ومنشآت التكرير، متضمنة المعيار الكارتوجرافي لشركة شل العالمية (Shell Standard باللونين الأحمر والأخضر)، ورموز الخامات التعدينية والمحاجر مع ترجمة عربية كاملة.

أضخم مكتبة ألوان و ColorBrewer

أكثر من 207 ستايل ألوان لمختلف التخصصات في مجلد Color For ArcGIS، وسكيمات ColorBrewer للخرائط الموضوعية، وتدرجات الارتفاعات الرقمية ETOPO1 و Hypsometry، مع 57 ستايل Esri الرسمية لبرنامج ArcMap.

البيئة والغطاء الأرضي والنقل

تصنيفات منظمة الأغذية والزراعة (FAO-LCCS) للغطاء الأرضي، وتربة SSURGO، واستخدامات الأراضي الحضرية (UrbanAtlas/CORINE)، وشبكات الطرق (OSM / MUTCD)، والحدود الإدارية الدولية (NaturalEarth/GADM).

قلب المستودع: خطوط وقوالب وسكربتات

مجلد مركز الرموز والخطوط المنظم (Styles and Fonts Symbol) ويحتوي على 8 مجلدات فرعية تضم الخطوط التخصصية (OTF/TTF)، وقوالب الخرائط (MXD/GDB)، وأدوات معالجة NCGMP09، ورسومات متجهة Inkscape/AI.

لماذا ستايل ArcMap (.style) هو الأساس؟

عندما طوّرت Esri برنامج ArcGIS Pro اعتمدت صيغة جديدة كلياً (.stylx)، ولكنها وفّرت آلية استيراد مباشرة تقرأ ستايلات ArcMap القديمة (.style) بكل سلاسة. بالعكس، فإن برنامج ArcMap القديم لا يمتلك أي خوارزمية لقراءة ملفات SQLite و CIM الخاصة بـ ArcGIS Pro.

إذا كنت تعمل على ArcGIS Pro: يمكنك استخدام أي ملف .style أو .stylx بحرية تامة!
إذا كنت تعمل على ArcMap 10.x: استخدم دائماً ملفات .style أو النسخ العربية *-AR.style فقط.

ماذا عن ستايلات QGIS المحوّلة؟

ستجد داخل مجلد Styles and Fonts Symbol/03_from QGIS to ArcMap_Style مجموعة ستايلات تم تحويلها من بيئة QGIS مفتوحة المصدر إلى ستايلات ArcMap.

نظراً لاختلاف محركات التصيير (Rendering Engines) بين QGIS و ArcGIS، فإن هذه الستايلات استرشادية وتوفر أشكالاً جميلة، لكنها ليست بمعيارية رموز FGDC أو Esri الأصلية، لذا يُنصح بمراجعتها بصرياً قبل اعتمادها في الخرائط الرسمية.

BILINGUAL ARABIC EDITIONS

النسخ العربية ثنائية اللغة: 40 ملفاً • 45,589 رمزاً

تم الحفاظ على كل ستايل أصلي بالإنجليزية كما هو دون المساس به، وأُنشئت بجانبه نسخة عربية داخل مجلد فرعي Arabic بتسمية ثنائية: «عربي | English» — مثل «بئر نفط | Oil Well»، لكي يبحث المستخدم العربي بلغته الأم وتظل الرموز والأكواد مطابقة للمعايير العالمية.

بحث فوري بالعربية والإنجليزية

الاسم الإنجليزي محفوظ كاملاً بعد الفاصل (|)؛ اكتب "فالق" أو "fault" أو الكود القياسي (FGDC أو AXX0 أو Zt) وسيظهر الرمز نفسه فوراً في Symbol Selector.

ملف مراجعة CSV لكل ستايل

Translations_*.csv: field | id | key | original | arabic | new_value | status

يتيح مراجعة وتعديل الترجمة بسهولة عبر برامج الجداول مثل Excel.

إعادة التوليد بضغطة زر

00 - Arabic Translation Kit / translate_styles.py all

سكربت Python آلي يعيد توليد جميع النسخ مع فحص SHA256 لضمان سلامة الملفات الأصلية.

SETUP GUIDE

طريقة الاستخدام والتثبيت في 3 خطوات بسيطة

خطوات سهلة ومباشرة لإضافة الستايلات إلى بيئة عملك في ArcMap أو ArcGIS Pro والاستفادة من النسخ العربية ثنائية اللغة فوراً.

1

حمّل أو انسخ المستودع

استنسخ المستودع عبر Git أو حمّل المجلدات المطلوبة إلى جهازك:

git clone https://github.com/ahmadibrahim4geo/ArcMap-Style-Collection.git
2

ثبّت الخطوط أولاً (ضروري جداً)

افتح مجلد 04_Fonts أو مجلدات Fonts في الجيولوجيا، حدد جميع الخطوط (OTF/TTF)، انقر بالزر الأيمن واختر Install for all users لضمان ظهور الرموز الجيولوجية دون تشوه.

3

أضف الستايل لبرنامجك وابحث

في ArcMap: Customize › Style Manager › Add Style to List واختر *-AR.style.
في Pro: Insert › Add Style واختر *-AR.stylx.
ثم ابحث في Symbol Selector بالعربية أو الإنجليزية!
