ABOUT THE COLLECTION

ما هي هذه التجميعة؟ ولماذا هي مهمة؟

المشروع كله عن ستايلات الأرك ماب. تجميعة قديمة تشمل ستايلات Esri الرسمية وتجميعات من الإنترنت، منظمّة في 27 مجلدًا موضوعيًا. الأرك برو يقدر يفتح ستايلات الأرك ماب ويستخدمها عادي، لكن العكس لا يحدث — لذلك حافظنا على نسختي .style و .stylx معًا كلما أمكن.

جيولوجيا معيارية FGDC & GeMS

Alaska DGGS و BGS 50k و Geology 24K و USGS FGDC-GeMS و OF2005-1314 للصخور والأزمنة الجيولوجية — بالأكواد الرقمية والألوان المعتمدة.

هيدرولوجيا وشبكات مياه

رموز الهيدرولوجيا والمرافق (Utilities + Water/Wastewater) وشبكات المياه — ستايلات ArcMap و Pro مع نسخ عربية.

بترول وتعدين وتربة

ستايلات البترول (بما فيها Shell أحمر/أخضر) والتعدين وتربة SSURGO بأكواد FAO — مترجمة مع بقاء الأكواد والاختصارات.

ألوان ColorBrewer و Esri

أكثر من 200 ستايل ألوان: ColorBrewer و ETOPO1 و Hypsometry و Web Colors و 57 ستايل Esri الأصلية من ArcMap.

نقل وغطاء أرضي وسكان

النقل (OSM/MUTCD) والغطاء الأرضي (FAO-LCCS) والسكان والاستخدام الحضري (UrbanAtlas/CORINE) والحدود الإدارية.

خطوط + قوالب + سكربتات

مجلد Styles and Fonts Symbol المنظم: ستايلات ArcMap و Pro، ومحوَّلات QGIS، وخطوط FGDC، وقوالب MXD/GDB، وأدوات وسكربتات.

SETUP IN 3 STEPS

طريقة الاستخدام في 3 خطوات

1

حمّل أو انسخ المستودع

git clone https://github.com/ahmadibrahim4geo/ArcMap-Style-Collection.git

2

أضف الستايل لقائمتك

ArcMap: Customize › Style Manager › Add Style واختر *-AR.style للعربية — Pro: Insert › Add Style واختر *-AR.stylx.

3

ابحث وطبّق الرمز

ابحث في Symbol Selector بالعربية (بئر، فالق، غابة، خزان...) أو بالإنجليزية، وثبّت الخطوط من مجلد Fonts أولًا.
